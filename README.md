# QQ 群重要消息过滤（路线 B）

目标：只把重要群消息筛出来给自己看，不在群里发言。

## 怎么跑（电脑上）

0. 前置：SnowLuma 需要你自己下载安装（不随本项目打包）。装好后在看板的「SnowLuma 连接」页填它的目录，看板会自动拉起；也可以手动先开 SnowLuma。
1. 装依赖：`pip install -r requirements.txt`
2. 跑：`python dashboard.py`
3. 浏览器打开 http://127.0.0.1:8090，在「SnowLuma 连接」页确认已连接。
4. 群、关键词、发言人、模型、密钥、推送都在网页里配；在测试群发几条消息，看「今天的重要消息」和控制台。

## 规则

- 只读：不发群消息，不私聊发消息。
- 白名单 fail-closed：没填的群一律丢弃，不发给 AI。
- 本地先粗筛（群 / 重要发言人 / 关键词 / @），候选才调 DeepSeek 精筛。
- 结果只写本地文件，跑通测试群后，再一个一个加真实群。

## 版本保存（本地 git 就够，不用推 GitHub）

```bash
git init
git add .
git commit -m "第一版：只读粗筛能跑"
```

- 改之前先提交一个能跑的版本，改错了才有得回。
- 看改了什么：`git diff`
- 放弃还没提交的修改：`git restore qq_filter_route_b.py`
- 回到上一个已提交的版本：`git log --oneline` 找到那次提交，再 `git reset --hard <提交号>`
- 想试个有风险的改法：先 `git checkout -b try-xxx` 开个分支，试坏了删分支，试好了再合并回主分支。

注意：`.gitignore` 已经排除了 `*.jsonl` 和 `.env`，Key 和运行结果不会被提交。但代码里填的群号如果以后要推远程，推之前要先清掉。
